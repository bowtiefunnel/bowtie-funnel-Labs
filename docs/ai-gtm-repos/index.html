AI for GTM Systems — GitHub Repo Directory

A curated directory of open-source GitHub repos useful for building AI-powered go-to-market systems — agent frameworks, workflow automation, web/lead data collection, MCP servers into the GTM stack, open-source CRM/support/lifecycle infra, AI outbound tooling, and analytics. Every repo was checked live against the GitHub API (not pulled from memory) so stars and descriptions are current. This is a first-pass overview — categories and picks are a starting point to refine, not a final list.
